Portfolio project · Full-stack web application

FuelControl — Fleet Fuel Management

A full-stack system for tracking and controlling how much fuel each vehicle in a fleet uses.

The problem
Fleets that track fuel on paper or spreadsheets struggle to see who is fueling what, enforce per-vehicle limits and spot unusual consumption early.
The solution
A role-based web app where vehicles are registered with fuel quotas, fuel requests are checked against those quotas in real time (over-limit requests are rejected), and a dashboard shows consumption by vehicle, with an AI copilot that surfaces insights.
My contribution
I built it end to end: the React front end, a Node.js/Express REST API with JWT authentication and role-based access control, and the PostgreSQL database — including a MySQL-to-PostgreSQL migration during development.
  • React
  • Node.js
  • Express
  • PostgreSQL
  • JWT auth
